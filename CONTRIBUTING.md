# Contributing

- Read PROJECT_CONTEXT.md and ROADMAP.md first.
- Keep demo behavior explicit; never connect real payment or fulfillment.
- Keep Persian and English copy in sync.
- Preserve source provenance and original product text.
- Avoid dead buttons and fake success states.
- Keep GitHub Pages static export working.
- Never commit credentials or secrets.
- Add tests for logic changes.
- Run typecheck and production build.
- Update roadmap, changelog, and project context with verified progress.
