# GlobalCart 1.0.0 — Stable portfolio demo

GlobalCart 1.0.0 is the first stable release of the independent GlobalCart portfolio project. It packages the bilingual marketplace simulation, the offline-first catalog, dedicated product pages, responsive multi-image galleries, pricing provenance, discovery tools, local demo shopping flows and the bilingual engineering case study.

## Included in this release

- Persian RTL and English LTR storefront with category navigation, search, filters, sorting, recommendations and saved searches.
- A committed 1,000-product Amazon Berkeley Objects selection, with self-hosted optimized product galleries and source attribution.
- Dedicated static product pages, responsive image gallery controls, related products and product comparison.
- Deterministic illustrative USD estimates with explicit provenance, TGJU USD-to-Toman conversion and freshness disclosure. These are not seller quotes.
- Browser-local favorites, comparison, recently viewed, cart and simulated checkout.
- A bilingual portfolio case study with architecture, data flow and database ERD.
- Go/PostgreSQL backend foundations and internal demo commerce/admin/seller services, without public production endpoints.

## Demo boundaries

GlobalCart is a portfolio simulation, not a live retailer. It does not sell goods or process real payments, reserve inventory, ship orders, pay sellers or refund money. The catalog source does not provide verified retailer prices, ratings or stock for the selected data; displayed amounts are GlobalCart estimates. Translation remains intentionally paused.

## Release verification

The release workflow runs TypeScript validation, unit tests, a production static build, the full cross-browser Playwright/axe suite, a historical secret scan and public smoke checks for the storefront, a representative product page and the case study. The public Lighthouse workflow independently audits all six mobile/desktop route combinations against the existing performance budgets.

GitHub-hosted browser and Lighthouse results are automated regression evidence, not physical-device or real-user field measurements. Actual physical desktop/mobile review, real platform screen-reader review, complete human RTL/LTR inspection and eligible field Core Web Vitals/CDN evidence are not claimed as completed in this release.
